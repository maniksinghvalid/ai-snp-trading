<objective>
Build `SimulatedBarFeed` (BT-04): the historical 5m bar source that replaces the live moomoo
SDK push stream. It downloads 5m bars via the reused `bot.scanner.fetcher` kernel, routes
every frame through `get_ticker_frame` (Pitfall 3 column-casing), caches responses to CSV so
backtestable history grows past the yfinance rolling window over time, and replays bars as
`BarEvent`-shaped dicts in chronological order — computing session-running `hod`/`lod`/
`cum_volume` per code (the fields the live `BarAggregator` produces and the `SignalEngine`/FSM
consume).

The feed is also the phase's sole DATA-SOURCING module: it exposes the point-in-time setup
accessors the harness (06-05) needs — daily bars for `_evaluate_symbol`, a synthetic
`TodayPrice`, 5m frames for `_compute_tod_baselines`, and premarket-high derivation.

Purpose: isolate all yfinance/CSV/normalization/window concerns in one module with one test
file, so the execution simulator and harness build against a clean bar-replay contract.
Output: `backtester/feed.py`, filled `tests/backtester/test_feed.py`.
</objective>
