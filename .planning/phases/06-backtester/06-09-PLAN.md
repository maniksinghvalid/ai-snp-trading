clobber (CR-01), the missing watchlist gate (CR-06), and the missing EOD/end-of-run force-close

beyond a single trading day.

in place, wire the harness so each day is replayed with its OWN premarket highs and watchlist, and
so every position reaches CLOSED and lands in the trade log — restoring live/backtest parity for
multi-day runs (BT-01/BT-02/BT-03).

verification-required behaviours (a/b/c/d). No `bot/` behaviour is changed — the harness reuses the
unmodified `PositionManager.force_close_all` and `SignalEngine`, and only rebinds module-level
`now_et` clocks in-process for the duration of `run()`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| per-day setup state → replay | Each day's premarket highs and watchlist must be isolated; cross-day bleed is the CR-01/CR-06 defect class |
| replay clock rebind → live modules | Rebinding module-level `now_et` must be restored in `finally` so it never leaks to other in-process code |
| watchlist filter → entries | Only filtered/capped codes may enter; management must never be gated by the watchlist |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-09-01 | Tampering | cross-day premarket-high clobber | mitigate | CR-01: per-day highs stored in `_premarket_highs_by_day`, applied at the top of `replay_day` for the day being replayed only |
| T-06-09-02 | Elevation of privilege | unfiltered --symbols trading despite daily filter | mitigate | CR-06: entry branch gated on the capped/ranked persisted watchlist; management still runs for all bars |
| T-06-09-03 | Repudiation | positions open at range end silently dropped from the report | mitigate | CR-05: EOD/end-of-run `force_close_all` marks every position CLOSED and `_capture_closed_trades` records it with a real force_close exit price |
