<objective>
Close BLOCKER Gap 1 from 06-VERIFICATION: `SimulatedBarFeed._materialize_bars` and
`_load_premarket` iterate the raw yfinance-sourced frame with no `dropna`, so an all-NaN row
— the NORMAL union-index padding a real multi-ticker `yf.download(group_by="ticker")` produces
whenever a symbol lacks a bar at a timestamp its peers have (halts, illiquid names, staggered
premarket coverage) — either crashes `_materialize_bars` at `cum_volume += int(row["volume"])`
with `ValueError: cannot convert float NaN to integer`, or (in `_load_premarket`) silently
carries a NaN into `premarket_highs()`'s `max(...)`, making Gate 1's `close > premarket_high`
evaluate `x > NaN → False` for that symbol for the rest of the day (a silent no-trade that the
CR-03 coverage guard cannot catch, because the day DOES have bars — just NaN ones).

Purpose: this is exactly the multi-symbol ("500-symbol scale", BT-04's own wording) case the
backtester exists to serve. Without the guard the tool crashes or produces silently-wrong
results on realistic data, so no report it emits can "confirm live/backtest code parity".

Output: `backtester/feed.py` with a `dropna(subset=['open','high','low','close','volume'])`
before the per-row loop in BOTH `_materialize_bars` and `_load_premarket` (covering the
CSV-cache-hit path, since cached files preserve NaN rows written by an earlier unguarded
fetch), plus a regression test that reproduces the union-index NaN-padded frame and proves the
feed loads without raising and produces no NaN premarket high. No `bot/` code changes.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| raw yfinance frame → feed materialization | yfinance is an untrusted external data source; a real multi-ticker download routinely contains all-NaN union-index padding rows that must be filtered before numeric conversion |
| CSV cache file → feed materialization | a cache file written by an earlier (unguarded) fetch can contain NaN rows; the cache-hit path must apply the same guard as the network path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-10-01 | Denial of Service | `_materialize_bars` int(NaN) crash | mitigate | `dropna(subset=['open','high','low','close','volume'])` before the per-row loop so a NaN row can never reach `int(row["volume"])` and abort the whole backtest |
| T-06-10-02 | Tampering | NaN silently poisoning `premarket_highs()` max() → Gate 1 always False | mitigate | same dropna in `_load_premarket` so no NaN high is stored; a symbol with no valid premarket bars is omitted from the highs dict rather than mapped to NaN |
| T-06-10-03 | Tampering | stale CSV cache preserving NaN rows | mitigate | dropna sits after `sort_index()` and before the loop on BOTH paths, so cache-hit loads are cleaned identically to fresh fetches |
| T-06-10-SC | Tampering | npm/pip/cargo installs | accept | No new package installs — uses the already-imported `pandas` and `pandas_market_calendars`; no `bot/` source edited |
