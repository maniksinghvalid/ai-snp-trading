<objective>
Build `SimulatedExecution` (BT-02 core mechanic) and the minimal `SimulatedGateway` stub —
the two swapped leaves that let the live `PositionManager`/`SignalEngine`/`RiskEngine` pipeline
run offline with zero broker calls.

`SimulatedExecution` replaces `bot.execution.engine.ExecutionEngine`. It keeps the SAME public
surface (`consume_intent`, `manage_exit`) so `PositionManager` code is unchanged, but fills at
the NEXT bar's open (looked up via `feed.next_bar`) instead of polling a real broker — this is
the anti-look-ahead guarantee BT-02 requires (the signal used bar N's close; the fill can only
happen on bar N+1). It records every fill so the harness can build the per-trade log (the
`trades` DB table is never written by `bot/` code — verified — so the report cannot read it).

`SimulatedGateway` answers only the two async methods the reused pipeline calls offline:
`get_positions` (Gate 4 concurrent-cap read) and `get_equity` (only reached if
`cfg.sizing_equity_usd` is None; current rules.json sets 100000 so it is bypassed).

Purpose: isolate the fill model + the "no broker" contract in one module, proven by the
look-ahead fixture.
Output: `backtester/execution.py`, filled `tests/backtester/test_execution.py`.
</objective>
