The OrderIntent is the Phase 3→Phase 4 boundary artifact.

Output: `MoomooGateway.get_equity()`; `bot/risk/risk_engine.py`; fleshed-out `tests/risk/test_risk_engine.py` and a gateway test for `get_equity()` fallback.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RiskEngine → broker (get_equity) | Sizing math is driven by the live equity read; a corrupt/implausible value could drive an outsized position |
| RiskEngine → StateStore (pending_intents write) | Each emitted intent is persisted; a non-atomic/partial write would desync the D-09 pending tally from the durable record |
| Phase 3 → Phase 4 (OrderIntent) | The intent is an instruction boundary — it must NOT itself reach any real-money order path (paper-only invariant) |
