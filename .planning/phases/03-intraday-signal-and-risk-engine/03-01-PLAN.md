<objective>
Lay the Wave 0 foundation for Phase 3 (new packages + test scaffolds + dataclasses + migration 0003) and build the `BarAggregator` — a `CurKlineHandlerBase` subclass that turns the moomoo SDK's per-tick K_5M push stream into closed-bar events, firing strategy evaluation exclusively on `time_key` advance (SIG-02, no repainting) with a session-level dedup guard that survives subscription reconnects.

Purpose: SIG-02 is the no-repainting invariant the whole signal pipeline rests on; getting bar-close detection and the SDK-thread→asyncio bridge right here means every downstream gate evaluates only real, closed bars. The events dataclasses and migration 0003 are the shared contracts the SignalEngine (03-02) and RiskEngine (03-03) consume, so they must land in this first wave.

Output: `bot/signal/` and `bot/risk/` packages; `BarEvent`/`SignalEvent`/`OrderIntent` dataclasses; StateStore migration 0003 (`daily_trade_count`, `pending_intents`); `BarAggregator`; `MoomooGateway.get_market_snapshot()` (the D-01 premarket-high broker read, placed in wave 1 so the 03-02 fetch helper can consume it); and the Wave 0 failing test scaffolds for all three slices.
