## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02 | Tampering | Wikipedia table structure changed / spoofed | mitigate | `pd.read_html` upgrades HTTP→HTTPS; validate `"Symbol" in df.columns` before use; KeyError falls through to dated-cache fallback (Pitfall #4), never a silent wrong universe |
| T-02-03 | Tampering | yfinance returns malformed / NaN data | mitigate | get_ticker_frame drops all-NaN frames and returns None; lowercase-normalize columns; downstream filter (Plan 02) requires >=2 valid rows before passing to passes_daily_filters |
| T-02-04 | Information Disclosure / Integrity | thin watchlist from mass yfinance failure | mitigate | D-06 10% degradation gate: >=10% failures raise ScanDegradationError + log "scan_aborted_data_degradation" + durable append_audit surfacing (D-07) rather than publish a thin/false universe |
| T-02-05 | Tampering | data/ cache file manipulated on disk | accept | Cache is gitignored + operator-controlled single-user machine; cache write mirrors Phase 1 restrictive-perms intent; low-value local target |
</threat_model>
