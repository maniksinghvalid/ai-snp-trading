<objective>
Wire the two signal-engine gates that consume the Phase 7 foundation and data path: (1) rewrite the I3 RVOL check to use the time-of-day cumulative-volume baseline (SIG-RVOL-TOD) with a graceful legacy fallback, and (2) add the −2R daily circuit breaker gate (RISK-CIRCUIT) that halts new entries for the session, persists across restart, and auto-resets next day. The breaker's side effects that need the alerter and execution engine (D-08 cancellation + Telegram alert) live in the bot orchestrator, keeping SignalEngine dependency-light.

Purpose: This is where the RVOL fix becomes a real signal-frequency change (fair comparison at any time of day) and where the professional daily kill-switch takes effect. Both gates read state produced by 07-01 (store methods, config) and 07-02 (cum_volume, tod_baselines), so this plan runs after them. The breaker is realized-only (closed-trade P&L), never mark-to-market (Pitfall 3), and its trip is idempotent across a restart (Pitfall 6).

Output: TOD-normalized I3 gate + `_is_circuit_breaker_tripped` gate in `signal_engine.py`; one-shot breaker side-effects + startup handled-flag in `bot.service.bot`; extended signal-engine and bot tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tod_baselines / meta (DB) → signal gates | Persisted data drives whether entries are allowed |
| trades table realized P&L → breaker | Determines the session halt; must be realized-only |
| bot orchestrator → alerter/broker | Trip side effects (cancel, alert) must not crash the trade loop |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-16 | Spoofing | Stale breaker date from a prior session halts today's trading (or a today trip fails to persist) | mitigate | ET date-string comparison auto-resets stale entries (clear_circuit_breaker); trip is persisted via set_circuit_breaker_date before returning True (D-07); restart re-reads the flag (Pitfall 6) |
| T-07-17 | Tampering | Breaker trips on unrealized (mark-to-market) loss, halting entries wrongly | mitigate | Realized-only source get_daily_trade_stats (closed trades WHERE closed_at date) — open positions never contribute (Pitfall 3, D-05) |
| T-07-18 | Denial of Service | Circuit-breaker check issues an SDK call every bar on a tripped day | mitigate | Gate placed before the get_positions concurrent-cap call; tripped path returns None with no broker round-trip |
| T-07-19 | Spoofing | UTC/ET mismatch disables the TOD gate (always legacy) or mis-buckets | mitigate | session_date_str = now_et().date().isoformat(); bucket = time_key[11:16] ET clock (Pitfall 4); tests assert ET bucketing |
| T-07-20 | Denial of Service | Alert send failure crashes the bar loop | mitigate | alerter.send wrapped in try/except; failure logged, never propagated (ALERT-04) |
| T-07-SC | Tampering | Supply-chain: dependency installs | accept | No new packages installed this phase |
</threat_model>
