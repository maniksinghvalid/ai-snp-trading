Research rule (backtester/experimental/ibs_search/strategy_search.py `simulate`, close-fill branch):
- `exits = [j for j, (_, _, d0) in pos.items() if X[t, j] or t - d0 >= max_hold]` — exits popped BEFORE candidates are built
- `free = slots - len(pos)` (after the pops)
- `cand = [j for j in np.where(E[t])[0] if j not in pos and np.isfinite(Cv[t, j])]; cand.sort(key=lambda j: R[t, j])` — stable sort: IBS ascending, ties by column order
- trades recorded as `(dates[d0], dates[t], p / ep - 1)` with `p = Cv[t,j] * (1 - cost)`, `ep = Cv[d0,j] * (1 + cost)`
- IBS frame in the research: `ibs = (C - L) / (H - L)`; `E = (ibs < 0.2).fillna(False)`, `X = (ibs > 0.8).fillna(False)`, `R = ibs.fillna(99)`; simulate reads only `px["Close"]` and `px["Open"]`
- Research allocates `min(mtm / slots, avail)` and breaks on `alloc <= 0` — keep scenario price moves within ±5% so cash never binds (production never skips for cash)

IbsConfig fields used here (Plan 02): `ibs_entry_max`, `ibs_exit_min`, `max_hold_trading_days`, `sizing_equity_usd`, `position_pct_of_equity`, `max_concurrent_positions`, `universe`. Tests use `dataclasses.replace(ibs_cfg, ...)` for small slot/hold values.

Live snapshot row shape (12-RESEARCH.md "Live facts"): `{"code": "US.SPY", "update_time": "2026-10-04 21:19:04.863", "last_price": 769.64, "high_price": 772.65, "low_price": 767.145, "suspension": False, ...}`.
