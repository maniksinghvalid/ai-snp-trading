<objective>
Build `TelegramAlerter` (ALERT-01..04): a zero-dependency, fire-and-forget Telegram push client that POSTs to the Bot API `sendMessage` endpoint via stdlib `urllib` wrapped in `run_in_executor` (D-14), with message builders for the entry alert (ticker/size/entry/stop), every exit event (partial/breakeven/trail/stop-out/force-close), and the daily summary (trades/win-loss/realized-PnL/open-risk). Purpose: Observability for the unattended bot — the operator is told about every trade event and the daily outcome — without adding a dependency or ever risking the trade loop.
Output: bot/service/alerter.py (TelegramAlerter), green tests/service/test_alerter.py.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process → api.telegram.org | Fixed-host HTTPS POST; only data sent is chat_id + alert text |
| trade fields → alert text | ticker/exit_reason strings interpolated into HTML message |
| env secrets → transport | token used only to build the URL; never logged or sent in text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Information Disclosure | token in logs/alert text | mitigate | Pitfall 4: token only used in _API_URL.format(); never logged, never in text; warning logs carry no token |
| T-05-03-02 | Denial of Service | urllib POST blocks the loop | mitigate | run_in_executor keeps the POST off the event loop; _TIMEOUT_S=10 bounds the call; callers use create_task |
| T-05-03-03 | Spoofing | alert injection via ticker/exit_reason | mitigate | html.escape() on all free-text fields; Telegram parse_mode HTML only permits a safe tag subset |
| T-05-03-04 | Tampering | delivery failure propagates to trade loop | mitigate | ALERT-04: send() wraps everything in try/except Exception and swallows (never re-raises) |
| T-05-03-05 | Information Disclosure | MITM on Telegram transport | accept | urllib.urlopen uses HTTPS with default TLS verification (V9); fixed host, no user-controlled URL → SSRF surface is none |
</threat_model>
