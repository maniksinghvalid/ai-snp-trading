## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| trade strings → HTML report | ticker/exit_reason interpolated into the rendered HTML |
| plist EnvironmentVariables → process | paper-safety + Telegram secrets supplied to the supervised process |
| StateStore reads → report | concurrent position writes may race the report query |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Spoofing | HTML injection via ticker/exit_reason/phase | mitigate | html.escape() on every free-text field before interpolation in build_daily_html + _build_r_histogram |
| T-05-04-02 | Information Disclosure | secrets committed in plist | mitigate | plist ships placeholders only; deploy/README mandates chmod 600 + do-not-commit; verify task greps for a token-shaped string and fails if found |
| T-05-04-03 | Tampering | report read races position writes | mitigate | report query is read-only; StateStore WAL mode (Phase 1) allows concurrent read; no schema mutation in Phase 5 |
| T-05-04-04 | Denial of Service | report file I/O blocks the loop | mitigate | build_daily_html + write_reports run via run_in_executor in _job_eod_report (off the event loop) |
| T-05-04-05 | Denial of Service | crash loop burns CPU | mitigate | launchd ThrottleInterval (D-06) from service.launchd_throttle_interval_s; D-06 crash-loop Telegram alert threshold configured |
| T-05-04-SAFE | Elevation of Privilege | supervised process trades real money | mitigate | plist EnvironmentVariables hardcode PAPER_TRADING=true + FUTU_TRD_ENV=SIMULATE; paper guard (SAFE-01) still runs in the readiness gate |
</threat_model>
