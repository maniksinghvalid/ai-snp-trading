<objective>
Build the `TradingBot` orchestrator (SVC-01): one always-on long-lived process (D-01) whose `AsyncIOScheduler` on the single shared asyncio loop (D-02) registers the daily lifecycle cron/interval jobs — premarket scan, market-open subscribe, intraday re-scans (~30 min across 09:55-12:55 ET, SCAN-07), nominal 15:51 force-close, and the 15:55 EOD report — each a non-blocking coroutine wrapping the existing Phase 1-4 functions. Session-scoped state rolls over lazily by ET session_date with no reset job (D-04). Implements the D-08 hard startup readiness gate (paper guard → startup_reconcile → reconstruct → enable entries) and a full graceful-shutdown handler (D-07) that — via the kill switch — flushes all positions, writes a shutdown audit entry, closes the gateway cleanly, and fires a final "bot stopped" Telegram alert. `KillSwitch.register_flush(position_manager.flush_all)` is registered BEFORE the loop starts, closing the carry-forward obligation R-04-01 / T-04-21. Adds `bot/main.py` (component composition) and `bot/__main__.py` (`python -m bot`).

Purpose: First time all of Phases 1-4 run as one unattended process. Every timing value is config-driven (CFG-01) so no schedule literal is hardcoded.
Output: bot/service/bot.py (TradingBot), bot/main.py, bot/__main__.py, green tests/service/test_bot.py.
</objective>
