## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| broker health → entry flag | get_global_state result gates new-entry placement |
| outage window → exits | exits remain armed; a needed stop-out must not be dropped |
| reconnect → broker truth | startup_reconcile re-establishes authoritative state before entries resume |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Elevation of Privilege | entries placed during OpenD loss | mitigate | D-09: _on_disconnect sets bot._entries_enabled=False within one poll cycle before any reconnect attempt |
| T-05-02-02 | Tampering | stale state after reconnect | mitigate | D-11: _on_reconnect re-runs startup_reconcile (broker truth wins) + re-subscribe BEFORE re-enabling entries |
| T-05-02-03 | Denial of Service | reconnect storm hammers OpenD | mitigate | D-10: capped exponential backoff (initial→cap from rules.json); poll cadence unchanged |
| T-05-02-04 | Information Disclosure | disconnect alert leaks internals | mitigate | alert text is a fixed template (no token, no raw exception, no credentials) — Pitfall 4 |
| T-05-02-05 | Tampering | exit dropped during outage | mitigate | D-09: watchdog toggles ONLY the entry flag; exits stay armed and queue to fire on reconnect |
</threat_model>
