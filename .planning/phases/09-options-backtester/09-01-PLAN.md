<objective>
Build the offline options data layer: extend `MassiveDataSource` with the two options-specific
endpoints (contracts reference + `O:` daily aggregates), add the read-through cache, and expose a
per-decision-day chain view that structurally cannot leak future bars.

depends on its row shapes. It also carries the one research finding that constrains the whole
phase — the ~24-month option-aggregates entitlement ceiling — which must be re-pinned live before
the hypotheses doc (Plan 09-02) declares IS/OOS windows.

Output: `backtester/options/{__init__,data}.py`, two new `MassiveDataSource` methods,
`tests/backtester/options/{__init__,conftest,test_data}.py`, and a dated, verified record of the
Massive entitlement window in `data.py`'s module docstring.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI args → cache filesystem paths | `--symbols` and derived option tickers are interpolated into cache filenames under `backtester/cache/massive/` |
| local process → api.massive.com | `MASSIVE_API_KEY` crosses this boundary on every request |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-I1 | Information disclosure | `MassiveDataSource.fetch_contracts`, `cached_option_bars` | mitigate | Key travels only in the `Authorization: Bearer` header via the existing `_get_json`; never appended to a URL, never printed. Acceptance criterion greps for key-in-URL in T-09-02. |
| T-09-T1 | Tampering (path traversal) | cache filename construction | mitigate | `_SYMBOL_RE.fullmatch(underlying)` and `_OPTION_TICKER_RE.fullmatch(occ_ticker)` reject anything containing `/`, `..` or `:` beyond the fixed prefix, BEFORE `os.path.join` — extends the existing T-06-03 precedent; covered by `test_cache_filename_rejects_traversal`. |
| T-09-E1 | Elevation of privilege | `backtester/options/data.py` | mitigate | Module imports nothing from `bot.gateway`/`moomoo`; the backtester can never construct a broker session or place an order (mirrors `backtester/run.py`'s stated invariant). Acceptance criterion greps for it. |
| T-09-D1 | Denial of service (self-inflicted rate limit) | bulk backfill | mitigate | Mandatory read-through cache (D-06) plus the existing 429 `Retry-After` backoff; `load()` fetches the contracts reference once per underlying and narrows expiries/strikes before per-contract bar calls. |
| T-09-SC | Tampering (supply chain) | dependencies | accept | Phase installs zero new packages (09-RESEARCH § Package Legitimacy Audit: not applicable); no `pip install` task exists in this plan. |

**Finding: no high-severity threats.** This plan is an offline, single-process data fetcher with one
outbound HTTPS destination, no inbound surface, no authn/authz, and no PII.
