the equity-watchlist universe for super_bull_call, call-only screening, the debit entry path

scan. main() is deliberately NOT changed here — it keeps loading only the first strategy via
load_options_config, so no bull-call position can be opened in production until plan 11-06 has
wired the debit manage path and switched main() to the book.

| Boundary | Description |
|----------|-------------|
| equity watchlist codes (other process) → options entry scan | codes become screen inputs and, if a spread qualifies, paper orders |
| strategy config → sizing/caps | a per-strategy cap mistakenly made global (or vice versa) changes capital at risk |
| position/alert text → Telegram HTML | underlying codes and strategy names are interpolated into HTML alert bodies |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-11-04 | Tampering | _try_open strategy attribution | mitigate | every new position stores strategy_name = cfg.name of the scanning strategy; tests assert it for both books |
| T-11-19 | Elevation of Privilege (capital) | per-strategy vs global caps | mitigate | breaker/BP headroom/busy computed over ALL active positions; only entries/day and concurrent filtered by strategy_name; six dedicated D-22 tests |
| T-11-20 | Tampering | bull-call entry skipping IV gate | accept | by design (D-05) — the entry gate is watchlist membership + debit/liquidity/DTE gates; defined-risk debit sized by size_debit_position |

| T-11-01 | Tampering | equity DB access from the service | mitigate | the service only calls read_equity_watchlist (mode=ro); no other code path opens equity_state_db |
