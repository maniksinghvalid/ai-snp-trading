|----------|-------------|
| options process → equity bot's SQLite DB (data/bot_state.db) | cross-process read of another bot's live state; the options bot must never write there |
| equity daily_scan codes → options entry scan | codes produced by another process become screen inputs for paper orders |
| options DB schema migration | shared runner migrates both DB files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | bot/options/universe.py | mitigate | read-only URI (mode=ro) is the only connect; no bot.state import (ast test); write through the connection raises OperationalError (test); grep gate: no INSERT/UPDATE/DELETE/DDL text in the module |
| T-11-04 | Repudiation | option_positions.strategy_name | mitigate | NOT NULL DEFAULT 'tasty_credit_spreads' (historically correct for every existing row); omit-None insert so no caller can write NULL attribution |
| T-11-13 | Denial of Service | read_equity_watchlist on a locked/corrupt DB | mitigate | bounded timeout (5 s default), catch sqlite3.Error, return [] → zero bull-call entries (fail closed, never crash the scan) |
| T-11-14 | Tampering | watchlist codes as input | accept | codes are only passed to get_stock_ids/screen_options (broker-side resolution rejects unknown codes); same-machine, same-operator process; values bound, never interpolated into SQL |
| T-11-15 | Tampering | _migration_0007 on the equity DB | accept | adds one unused column to the equity DB's already-unused option_positions table on its next restart (same pattern as 0006); no equity table touched |
| T-11-16 | Information Disclosure | warning logs include db_path | accept | local file path in local logs only; no secrets |
