## Decisions Made

1. Construction order: `signal_engine` built before `risk_engine` so the `signal_engine=signal_engine` kwarg to `RiskEngine` is valid. This is the canonical Pitfall 7 constraint — if order were reversed, `signal_engine` would be unbound at `RiskEngine` construction time.

2. No loop-dependent objects added to `main.py` (D-03): `BarAggregator` lives inside `TradingBot._do_startup_wiring()` which is called from `run()` after `asyncio.run()` has started the event loop. `main.py` only builds the loop-independent leaves.

3. Comment in `main.py` at Step 5d was written carefully to avoid mentioning `BarAggregator` by name — the acceptance criterion requires `grep -c 'BarAggregator|get_running_loop' bot/main.py == 0`, so the comment says "the loop-dependent aggregator stays in TradingBot.run()" without naming the class directly.
