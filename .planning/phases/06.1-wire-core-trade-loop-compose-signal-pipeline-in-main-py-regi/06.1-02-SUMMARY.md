# Phase 06.1 Plan 02: Gateway Push-Handler Seams and Reconcile-Once Drift Logic Summary

Wire the two gateway seams required by the Wave 1 parallel execution: `set_handler()` for push handler registration (BLOCKER-01) and a real `reconcile_once()` drift implementation replacing the no-op stub (SAFE-03/D-07).

## What Was Built

**Task 1 — MoomooGateway.set_handler() push-handler wrapper**

Added a thin `set_handler(self, handler) -> None` method to `MoomooGateway` that delegates to `self._quote_ctx.set_handler(handler)` and logs `push_handler_registered` with the handler class name. Placed adjacent to `subscribe()` to group quote-context delegation methods. Satisfies BLOCKER-01: the BarAggregator can now be registered as the K_5M push consumer before subscribe() is called.

**Task 2 — reconcile_once() drift logic + reconciliation_loop() signature update**

Replaced the no-op `reconcile_once(self) -> dict` stub (which returned `{"drift": {}}`) with real broker-truth-wins drift logic per SAFE-03/D-07. Three cases handled:

1. **Externally-closed** — code in `manager._positions`, absent from broker map, NOT in `manager._exiting`: DB UPDATE `phase='CLOSED'`, set `pos.phase = PositionPhase.CLOSED`, delete from `manager._positions`, audit `drift_closed_by_broker`, fire-and-forget `asyncio.create_task(alerter.send(...))`. Alert is scheduled before `del manager._positions[code]` so the next cycle finds nothing to re-close (anti-DDoS per T-06.1-RECONCILE-DDOS).
2. **Orphan** — broker has position, not in `manager._positions`: adopt using `_derive_lod_for_orphan` + `_compute_orphan_stop`, `INSERT OR IGNORE ACTIVE`, audit `drift_orphan_adopted`, subscribe feed.
3. **In-flight skip** — any code in `manager._exiting` is skipped to avoid racing a live `manage_exit()` (T-06.1-RECONCILE / Pitfall 6).

`reconciliation_loop()` signature extended from `(self, interval_s=75.0)` to `(self, store, manager, alerter, interval_s=75.0)`, passing all three through to `reconcile_once(store=..., manager=..., alerter=...)`. Ready for Wave 2 `asyncio.create_task(gateway.reconciliation_loop(...))` launch in `TradingBot.run()` (D-08).
