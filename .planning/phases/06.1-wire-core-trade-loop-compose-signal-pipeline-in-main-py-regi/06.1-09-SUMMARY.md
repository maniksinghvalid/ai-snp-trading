## Post-Merge Hardening (2026-06-25): Test given deterministic teeth (WR-01 properly closed)

The original concurrency test (`TestLoopVsExecutorConcurrency`) passed even when `self._lock`
was replaced with a no-op context manager — a false-green (WR-01 false-green failure mode).
The test ran only 6 executor readers with 1 iteration each, making contention too sparse
to manifest the race reliably.

**Hardening commit:** `862be63` — `test(06.1-09): give StateStore concurrency test teeth`

**What was added:** `TestStressRowFactoryRace` — a dedicated stress test using the
empirically-validated knobs from the WR-01 background analysis:

1. `sys.setswitchinterval(1e-6)` during the contended region (maximum GIL tumbling).
   Restored via `finally` — no global state leakage across tests.
2. 8 concurrent `threading.Thread` workers (>= 6 required), each running 1500 iterations
   (>= 1500 required) of all three row_factory-flipping read methods:
   `get_open_positions()`, `get_pending_intent_codes()`, `get_closed_trades()`.
3. Broad `except Exception` in the worker captures ALL corruption manifestations:
   - `TypeError`/`IndexError`/`KeyError` — plain tuple returned instead of `sqlite3.Row`
     (key access `row["position_id"]` fails on tuple)
   - `sqlite3.InterfaceError: bad parameter or other API misuse` — the primary symptom
     on CPython 3.14 when one thread's `row_factory=None` reset fires during another
     thread's `execute()` with a bound parameter, corrupting cursor internal state

**Mutation proof results (documented here for auditor reference):**

| Lock state | Corruption events | Test result |
|------------|------------------|-------------|
| Real `threading.RLock()` (current code) | 0 | PASS |
| No-op `_NoOpLock()` (temporary mutation) | 3,642 | FAIL |

The `store.py` mutation was applied, tested, and fully restored — `git diff bot/state/store.py`
is empty post-test. The `TestLoopVsExecutorConcurrency` class is retained for interface/shape
documentation but annotated that teeth come from `TestStressRowFactoryRace`.

Full suite post-hardening: **433 passed, 1 skipped** (was 432 passed — +1 for the new stress test).
