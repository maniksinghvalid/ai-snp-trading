## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process crash → state file | a crash mid-write must not corrupt durable state |
| filesystem → other OS users | the state DB/snapshot must not leak trade activity to other local users |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Tampering | atomic_write_json / StateStore | mitigate | Temp-file + `os.replace` with write→parse-validate→swap (D-10/PITFALLS #10); a crash mid-write leaves the original intact. Crash-injection test enforces this. |
| T-01-07 | Information Disclosure | state DB / snapshot file | mitigate | Write snapshot files with `0600` permissions; DB lives under gitignored `./data/` not `/tmp/` (PITFALLS §Security "State file in world-readable location"). |
