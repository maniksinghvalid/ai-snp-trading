<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator env / config → bot | `PAPER_TRADING`, `FUTU_TRD_ENV`, `FUTU_ACC_ID` are operator-supplied and can be misconfigured |
| bot → OpenD (127.0.0.1:11111) | localhost broker daemon; account-type truth comes from `get_acc_list()` |
| bot → broker order path (future) | the REAL-money path that must remain unreachable this milestone |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | paper_guard.assert_paper_account | mitigate | Triple independent fail-closed assertion (flag + FUTU_TRD_ENV + broker-reported trd_env for the explicit acc_id); ANY mismatch raises PaperGuardError before contexts are usable (D-04). A REAL account or flag/account mismatch can never reach an order path. |
| T-01-02 | Tampering | bot/safety/audit_log.py | mitigate | Append-only `"a"` mode, never truncates; refusal events are recorded so a bypass attempt leaves an immutable trail (SAFE-05). Test proves prior lines are preserved. |
| T-01-03 | Spoofing | account selection | mitigate | No account auto-selection (D-03); the operator must set `FUTU_ACC_ID` explicitly and the guard verifies that exact account's broker trd_env, preventing a wrong/spoofed account from passing. |
| T-01-04 | Information Disclosure | GatewayConfig / logs | mitigate | Never log `FUTU_LOGIN_PWD` or full config; the GatewayConfig dataclass must not echo credentials (PITFALLS §Security — mask credentials). No password is read or stored by the gateway. |
| T-01-05 | Denial of Service | OpenD connectivity | accept | Pre-flight `_check_opend_alive` raises a clear `ConnectionError`; if OpenD is down the bot cannot start (acceptable — bot is non-functional without OpenD by design). Watchdog/reconnect is Phase 5. |
| T-01-SC | Tampering | pip installs (requirements.txt) | mitigate | Only well-known, PyPI-verified, version-pinned packages (moomoo-api existing; numpy/jsonschema/structlog from RESEARCH STACK.md). No `[ASSUMED]`/`[SUS]`/`[SLOP]` packages introduced; all appear in research with confirmed versions. |
</threat_model>
