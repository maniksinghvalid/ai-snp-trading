## Gateway — `bot/gateway/gateway.py`

```python
async def get_stock_ids(self, codes: list) -> dict
    # {code: stock_id int}; ETF lookup first, ONE SecurityType.STOCK follow-up for the
    # remainder only. Unresolved codes are OMITTED (logs stock_ids_unresolved).
    # Raises GatewayError on a non-RET_OK from either call.

async def screen_options(self, stock_ids: list, right: str,
                         dte_lo: int, dte_hi: int,
                         delta_lo: float, delta_hi: float) -> list  # list[dict]
    # right is "C" or "P". One call covers ALL underlyings (STOCK_LIST filter),
    # so a full-universe scan is 1 call per right. Pages until last_page, bounded by
    # _OPTION_SCREEN_MAX_PAGES = 20 and by an empty-page break.
    # Raises GatewayError on a non-RET_OK page.

async def get_option_positions(self) -> dict
    # {option_code: signed int qty}. ONLY codes matching
    # _OPTION_CODE_RE = ^US\.[A-Z]+\d{6}[CP]\d+$ (SAFE-OG-01 — the human's US.SPY
    # equity position is invisible). SHORT legs come back NEGATIVE.
    # Raises GatewayError on a non-RET_OK.
```

Each `screen_options` row carries, in addition to every raw SDK column
(`option_name, price, theta, otm_probability, bid_ask_spread, ...`):

| key | source | note |
|-----|--------|------|
| `code` | raw | unchanged |
| `right` | `option_type` | `"C"`/`"P"`; falls back to the `right` argument if unrecognised |
| `strike` | `strike_price` | |
| `expiry` | `strike_date[:10]` | `YYYY-MM-DD` |
| `dte` | `left_day` | |
| `bid` / `ask` / `mid` | `bid_price` / `ask_price` / `mid_price` | |
| `iv` | `implied_volatility` | |
| `open_interest`, `delta` | raw | consumed directly by `leg_is_liquid` / `pick_strikes` |
| `u_stock_id, u_price, u_iv, u_iv_rank, u_iv_percentile, u_change_ratio` | flattened `underlying` dict | **all six are `None`** when the SDK sends its NoneDataType sentinel |

**`u_iv_rank` / `u_iv_percentile` are the SDK's FRACTIONS (0.066), not percents.**
The ×100 scaling to feed `passes_entry_gate(u={"ivr_pct", "ivp_pct", "change_pct"})`
is the service's job, exactly once. `u_change_ratio` unit is still unverified — the
read-only UAT probe is the check.

```python
class OptionsStore(StateStore):          # own DB: OptionsStore(cfg.state_db).open()
    insert_option_position(pos: dict) -> None      # pos.get() per column — omit nullables
    insert_option_leg(leg: dict) -> None           # right goes in under key "right"
    set_leg_entry(leg_id, order_id=None, price=None, status=None) -> None   # partial
    set_leg_exit(leg_id,  order_id=None, price=None, status=None) -> None   # partial
    set_position_status(position_id, status, *, closed_at=None,
                        close_reason=None, realized_pnl_usd=None) -> None
    get_option_positions(statuses: tuple) -> list  # each row has row["legs"] (rowid order)
    get_realized_pnl_on(date_iso) -> float         # closed_at LIKE 'YYYY-MM-DD%'
    count_opened_on(date_iso) -> int               # opened_at LIKE 'YYYY-MM-DD%'
    get_meta(key) -> str | None
    set_meta(key, value) -> None                   # upsert
```

- `get_option_positions(())` returns `[]` without hitting the DB.
- All the `set_*` partial updaters skip the SQL entirely when every optional argument
  is `None` — calling them defensively is free.
- `get_meta`/`set_meta` share the `meta` table with StateStore's circuit-breaker keys;
  pick a distinct key (e.g. `options_breaker_date`).

## Executor — `bot/options/execution.py`

```python
LegExecutor(gateway, cfg)                # cfg = OptionsConfig (CFG-01, no literals)

async fill_leg(code, side, qty, bid, ask, aggressive=False, on_placed=None)
    -> (order_id, avg_price, filled_qty) | None
async open_position(legs, qty, quotes, on_leg_placed=None, on_leg_filled=None)
    -> list[dict] | None
async close_legs(legs, quotes, aggressive=False, on_leg_placed=None, on_leg_filled=None)
    -> bool
```

**Callback contracts (all are awaited; pass coroutine functions):**

| callback | signature | when |
|----------|-----------|------|
| `on_placed` (fill_leg) | `async (order_id)` | immediately after EVERY placement, before any poll — and again on each escalation re-place |
| `on_leg_placed` | `async (leg, order_id)` | same moment, per leg — **persist `entry_order_id`/`exit_order_id` here**, it is awaited before the next leg is placed |
| `on_leg_filled` | `async (leg, order_id, price, filled_qty)` | after a leg's fill_leg returns non-None (fires on partials too in `close_legs`) |

- `quotes` is REQUIRED and is `{code: {"bid": float, "ask": float}}` — one snapshot the
  service takes (strategy legs carry `mid` only, never bid/ask). `close_legs` needs a
  quote for every leg code or that leg fails.
- `legs` for `open_position` come straight from `pick_strikes` (`{code, right, strike,
  side, mid}`) and are **not re-sorted** — long wings first is the risk control.
  Returned legs are `{**leg, "order_id", "entry_price", "filled_qty"}`.
- `close_legs` derives qty from `leg["filled_qty"]` if present, else `leg["qty"]`, and
  closes with the inverse side. It returns `False` if ANY leg did not fully close
  (it still attempts the rest) → service should mark NEEDS_ATTENTION and alert.
- `open_position` returning `None` means the filled legs were already unwound
  aggressively; the position row should go to ABORTED.
- Every `fill_leg` exit path cancels the working order — no resting limit is ever left
  behind. Escalation is `max_retries + 1` placements total.
- **Rate limits:** each attempt polls `get_order_status` every `poll_interval_s`
  (default 4.0s) — `order_list_query` is capped at 10 calls / 30s and is shared with
  the manage job. Keep `poll_interval_s >= 3.5` and serialise entry/manage with the
  one `asyncio.Lock` the design calls for.
