1) `async def fill_leg(self, code, side, qty, bid, ask, aggressive=False, on_placed=None) -> tuple | None`

   deliberate widening of the design's 2-tuple, because a TTL partial fill must tell the caller
   how many contracts actually filled.

     SELL → `bid if aggressive else mid - limit_buffer_usd`. `price = round(price, 2)` and floor at
     0.01 so a limit can never be <= 0.
   - `trd_side = _get_trd_side_buy() if side == "BUY" else _get_trd_side_sell()`.
   - `order_id = await self._gw.place_order(code, qty, price, trd_side)`; then, when `on_placed`

     lets open_position persist the order_id before the next leg is placed.

     `loop = asyncio.get_event_loop()`, `deadline = loop.time() + cfg.ttl_s`, and while
     `loop.time() < deadline`: `await asyncio.sleep(cfg.poll_interval_s)`, then
     `rows = await self._gw.get_order_status(order_id)`, match on `str(r.get("order_id")) == str(order_id)`,

2) `async def open_position(self, legs, qty, quotes, on_leg_placed=None, on_leg_filled=None) -> list | None`
   `quotes` is `{code: {"bid": float, "ask": float}}` — one snapshot taken by the caller. It is a
   REQUIRED parameter (see `<interfaces_verified>`: strategy legs carry `mid` only, never bid/ask).
   - Iterate `legs` in the given order — `pick_strikes` already returns LONG WINGS FIRST, so
     protection is bought before risk is sold. Do not re-sort.
   - For each leg: `q = quotes[leg["code"]]`; call
     `fill_leg(leg["code"], leg["side"], qty, q["bid"], q["ask"], on_placed=<wrapper>)` where the
     wrapper awaits `on_leg_placed(leg, order_id)` when that callback is not None.
   - On success await `on_leg_filled(leg, order_id, price, filled_qty)` (when not None) and append
     `{**leg, "order_id": ..., "entry_price": ..., "filled_qty": ...}` to the filled list.
   - Failure = fill_leg returned None OR `filled_qty != qty`. On failure:
     `await self.close_legs(filled, quotes, aggressive=True)`, log `open_position_unwound`, return None.
