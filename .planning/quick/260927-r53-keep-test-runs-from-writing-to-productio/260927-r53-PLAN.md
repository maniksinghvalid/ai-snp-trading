<objective>
Stop test runs from polluting the production log. `python3 -m pytest -q` from the repo root currently appends test events to `./logs/bot.log`, the same file the live equity and options bots write. On 2026-09-26 ~22:24Z, fake `options_reconcile_mismatch` (P1), `options_strategy_structure_mismatch` (M1/X1) and `leg_order_placed` (US.SPY260320P600000, O1/O2/O3) events nearly got mistaken for real broker events during incident forensics.

Root cause (already established, do not re-investigate): `configure_logging(log_dir=_DEFAULT_LOG_DIR)` defaults to the CWD-relative "logs". tests/test_main_wiring.py (`_drive_real_main`) and tests/options/test_dispatch.py drive the real `bot.main.main()`, which calls `configure_logging()` with no args. That installs a RotatingFileHandler on the ROOT logger, so every later test's structlog events land in ./logs/bot.log.

Purpose: tests only. Production logging behaviour must not change.
Output: one regression test (red first), then one session-scoped autouse conftest fixture that makes it pass.
</objective>

bot/safety/logger.py (read-only for this task; DO NOT EDIT):
- `_DEFAULT_LOG_DIR = "logs"`, `_DEFAULT_LEVEL = "INFO"` (module constants)
- `_configured = False` (module flag; the second call is a no-op while True)
- `def configure_logging(log_dir: str = _DEFAULT_LOG_DIR, level: str = _DEFAULT_LEVEL) -> None`. The defaults are bound at def time, so `configure_logging.__defaults__ == ("logs", "INFO")`. Monkeypatching `_DEFAULT_LOG_DIR` has NO effect.
- It installs `logging.handlers.RotatingFileHandler(os.path.join(log_dir, "bot.log"))` and a stderr StreamHandler on `logging.getLogger()` (root). `RotatingFileHandler.baseFilename` is an absolute path.
- bot/main.py and bot/options/service.py do `from bot.safety.logger import configure_logging` and call `configure_logging()` with no args. They hold the SAME function object, so patching the module attribute would miss them. Patching the function object's `__defaults__` reaches every caller.

tests/safety/test_logger.py already has an autouse fixture `reset_logger_state` that sets `bot.safety.logger._configured = False` plus `structlog.reset_defaults()` before each test, and restores both afterwards. The new test relies on it and adds no fixture of its own.

tests/conftest.py style: `#!/usr/bin/env python3` header, a module docstring with a "Provides:" list, `# ============================================================` section-header blocks, and a docstring on every fixture.
