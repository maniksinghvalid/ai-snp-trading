`async def _job_manage(self)` — same outer try/except shape. Guards: trading day;
`self._is_rth_now()`. Then `async with self._lock:`:
  - `await self.reconcile()` (steady-state — broker truth before any decision).
  - `positions = self._store.get_option_positions(("OPEN",))`; `if not positions: return`.
  - `codes = sorted({leg["code"] for p in positions for leg in p["legs"]})`;
    build `quotes` by calling `await self._gateway.get_market_snapshot(chunk)` for each
    `_chunks(codes, _SNAPSHOT_CHUNK)`, skipping a chunk whose `ret != _RET_OK`
    (log `options_snapshot_failed`), and mapping each row via `_rows(data)` to
    `quotes[row["code"]] = {"bid": row["bid_price"], "ask": row["ask_price"]}`.
  - `today = now_et().date()`; `unrealized_total = 0.0`.
  - Per position, wrapped in its own `try/except ... continue`:
      - `continue` when any leg code is missing from `quotes` (log
        `options_manage_missing_quote`) — `mark_spread` would KeyError.
      - `mark = mark_spread(p["legs"], quotes)`;
        `dte = option_dte(date.fromisoformat(p["expiry"]), today)`;
        `credit = float(p["credit_per_spread"])`; `qty = int(p["qty"])`.
      - `dec = manage_decision(mark, credit, dte, cfg)`.
      - When `dec` is None: `unrealized_total += (credit - mark) * _CONTRACT_MULTIPLIER * qty`;
        continue.
      - Otherwise `set_position_status(pid, "CLOSING")`; collect `exits = {}` in an
        `_on_exit_filled(leg, order_id, price, filled_qty)` callback that also calls
        `set_leg_exit(leg["leg_id"], price=price, status="CLOSED")`, plus an
        `_on_exit_placed(leg, order_id)` callback calling
        `set_leg_exit(leg["leg_id"], order_id=order_id, status="CLOSING")`.
      - `ok = await self._executor.close_legs(p["legs"], quotes,
        aggressive=(dec == "assignment_guard"), on_leg_placed=..., on_leg_filled=...)`.
      - When `ok`: `net_exit = sum(exits[l["code"]] for SELL legs) - sum(exits[l["code"]]
        for BUY legs)` (use `exits.get(code, 0.0)`);
        `realized_per_spread = credit - net_exit`;
        `realized_usd = realized_per_spread * _CONTRACT_MULTIPLIER * qty`;
        `set_position_status(pid, "CLOSED", closed_at=now_et().isoformat(),
        close_reason=dec, realized_pnl_usd=realized_usd)`;
        `await self._alerter.send(_fmt_exit(p, dec, realized_usd,
        realized_per_spread / credit * 100 if credit else 0.0))`;
        `append_audit({"event": "options_position_closed", ...})`.
      - When not `ok`: `set_position_status(pid, "NEEDS_ATTENTION")` + escaped alert
        (`close incomplete — check the account`) + `append_audit`.
  - Breaker, after the loop:
    `realized_today = self._store.get_realized_pnl_on(today.isoformat())`;
    `limit = -cfg.daily_loss_limit_pct / 100 * cfg.sizing_equity_usd`;
    `if realized_today + unrealized_total <= limit and
    self._store.get_meta(_BREAKER_META_KEY) != today.isoformat():`
    `set_meta(_BREAKER_META_KEY, today.isoformat())`, one alert
    (`<b>Options daily loss limit hit</b> — no new entries today`),
    `append_audit({"event": "options_daily_breaker", ...})`. The meta comparison is the
    once-only guard — do not add an instance flag (it must survive a restart).
